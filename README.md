# Stitch Ease — marketing site

The marketing home page for [Stitch Ease Designer](https://github.com/tamaradidproduct/stitch-ease-designer), a browser-based chart editor for knitwear designers.

- `public/index.html` — the site, a single static page (no build step)
- `.github/workflows/deploy.yml` — deploys `public/` to GitHub Pages on every push to `main`

Live at: https://tamaradidproduct.github.io/stitch-ease-site/
